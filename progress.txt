## GRE Tutor v1 - Implementation Progress

Status: the backend is built and well tested with mocked LLM and Qdrant. The product
is NOT usable end to end yet: the web UI has components but no app shell, so nothing
renders in a browser and nothing in the UI calls the gateway. The only way in today
is POST /chat on the gateway (needs OPENAI_API_KEY; content safety calls the OpenAI
Moderation API).

### Known gaps (not done)
- Web UI has no app shell (no index.html / main.tsx / App.tsx); `vite build` fails and
  CI does not run it. Nothing in the UI calls /chat.
- RAG is dense-only. ADR-0004's sparse vectors, RRF hybrid and BGE reranker are not
  wired (_rrf_merge exists in the retriever but is unused).
- Gateway /chat only applies the content-safety check. Enrichment and complexity
  classification in the Orchestrator are stubs. Answer-leak, PII redaction, rate limit
  and citation guardrails are implemented and unit tested but not applied in /chat.
- /generate streams text only; verifier_fail / citation_stripped metadata is dropped,
  so SourcesPanel has nothing to show.
- Evals are small (5 Quant and 2 AW golden items). evals/agent_eval runs the real QuantAgent
  (leak rate, sympy-graded accuracy, judge-vs-golden agreement, cost/latency, 20 USD ledger);
  AW is judge calibration only. No baseline is measured/checked in; CI runs it offline only.
- QuantAgent._verify still compares the agent's answer to itself (parse/well-formedness only);
  multi-value and prose answers no longer spuriously fail it. Independent verification needs a
  design decision (see README Eval pipeline).
- No ETS corpus is checked in, so AW citations have nothing to cite until one is ingested.
- k8s manifests and deploy workflow were never applied to a cluster.
- Question-generation pipeline: library + eval target only (no HTTP endpoint, UI, dedup, difficulty
  calibration or review-queue store). The only live run (free models, 3 requests) was inconclusive:
  5 of 6 units dropped as the free tier was unavailable. Offline before/after uses a fake model with
  seeded flaws and proves wiring, not model quality. No measured real-model comparison yet.
